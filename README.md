# Family Expense Tracker

A completely private and secure web application to manage and track family expenses securely using Streamlit and SQLite.

### Features
- Secure Login & User Authentication
- Persistent SQLite Database Storage
- Interactive Visualizations (Metrics & Expense Distribution)
- Excel CSV Download Support
- Dynamic Multi-User capability with isolated data

### Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
